01 — 04

Prepare the evidence

Canonical originals are already assembled. Denoising prepares the speech; carrier surveys measure the originals, where timing references remain intact.

05a — QA

Make the listening decisions

Bounded pilots qualify the method before full-tape planning. Use the listening desk for comparisons, map checks and explicit acceptance of the resulting plans.

Render the archive

Apply accepted flutter maps, survey Quindars in completed defluttered channels, freeze one speed curve per tape, then render retimed audio.
