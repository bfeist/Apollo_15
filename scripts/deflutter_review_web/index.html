04 / DELIBERATE ACCEPTANCE
Approve a defined scope
Methodology acceptance requires qualified carrier evidence, cross-tape pilots, fresh holdouts and representative listening. Production acceptance additionally requires an accepted methodology and passed full-channel map checks for every included channel.
Proposals and failed numeric checks remain excluded from correction. Conservative bypass intervals stay in the continuous output. Listening flags retain failed holdouts and exclude affected channels from production acceptance.
The preview will list exact tapes, channels, intervals, exclusions and blockers before any acceptance record is written.
Approval writes evidence records only. Production rendering is a separate, explicit CLI action.
